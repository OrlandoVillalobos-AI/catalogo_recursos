--- 5) Nota tecnica sobre la interfaz de GitHub ---
  La API de GitHub rechaza las revisiones con veredicto REQUEST_CHANGES o APPROVE
  cuando el autor del Pull Request es el mismo usuario autenticado (error 422:
  'Review Can not request changes on your own pull request'). Como en esta ejecucion
  el propietario y el colaborador son el mismo usuario, la revision con veredicto y el
  comentario posterior se registran como comentarios de revision (event=COMMENT), que
  quedan igualmente versionados en el hilo del Pull Request y cumplen la funcion de
  solicitar el cambio antes de aprobar, tal como exige el paso 19 de la practica.
